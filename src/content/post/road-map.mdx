2024 年中的时候曾经用 `next.js` 折腾过新的博客，但是由于 Cloudflare 的各种环境问题以及框架复杂度。所以最终还是选择用 `Astro` 作为搭建博客的基础框架。

## Stack

新的站点使用了下面的几种技术:

- Astro (基础框架)
- React (UI 框架)
- ShadCN (UI 组件)
- TailwindCss (功能优先的 CSS 框架)
- Netlify (部署平台,由 CloudflarePage 转过来的...)
- Shiki (代码高亮)

## 为什么使用 Astro

首先它足够的简洁，虽然提供的功能较为简单，但是对于一个简单的博客已经是足够了。而且 Astro 的 [群岛架构](https://docs.astro.build/zh-cn/concepts/islands/) 可以很容易的与其他 UI 框架结合，比如我的这个站点就是使用 `Astro + React` 搭建的 (至于为什么不选择 Vue,只是单纯的不喜欢 vue 的写法而已)。

其次, 我很喜欢 Astro 的 `Content Loader`(Astro v5 版本前的 Content Collection 也很棒)。最初使用 next.js 时，我就很喜欢 [ContentLayer](https://contentlayer.dev/),但是由于作者的"断更",以及无法在 Cloudflare 上部署的问题,导致我放弃使用 next.js,转而使用对内容集合天然支持的 Astro。

## 迁移是否方便

如果你是从 next.js 迁移过来，我个人觉得还是没有什么复杂度(可能我的要求并不是很高...),Astro 也是基于文件路由的，这也是我没有直接用 React ，而是选择它的一个理由。

上面说过的, Astro 可以很好的集成 `React`，这也就意味者你可以使用 React 庞大生态中的各种组件、hooks,这个也很棒!
